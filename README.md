# Desktop PNG Pet 🐾

> *"80% CODE IS НЕЙРОСЛОП"* — честное признание автора

Маленькое Win32-приложение, которое берёт `image.png` и вешает его поверх всех окон как прозрачную картинку. Без рамки, без заголовка, без вопросов. Просто картинка. Просто поверх всего. Просто потому что может.

---

## ✨ Что это умеет

- 📌 **Всегда сверху** — `WS_EX_TOPMOST`, картинка никуда не денется
- 👻 **Прозрачный фон** — используется `UpdateLayeredWindow` с альфа-каналом (`ULW_ALPHA`), так что PNG с прозрачностью отображается как надо
- 🖱️ **Перетаскивается мышкой** — зажми ЛКМ и тащи куда хочешь (через `WM_NCLBUTTONDOWN` + `HTCAPTION`, как будто это настоящее окно, хотя это не оно)
- 🚫 **Никакого интерфейса** — ни кнопок, ни меню, ни заголовка, ни стыда
- 🖼️ **GDI+ под капотом** — да, всё ещё жив, всё ещё рендерит

---

## 🔧 Как собрать

### Требования
- Windows (любая, где есть `gdiplus.dll` — то есть любая)
- Компилятор C++ с поддержкой C++17 (`std::filesystem`)
- Ссылки на библиотеки: `gdiplus.lib`, `user32.lib`, `gdi32.lib`

### MSVC (из командной строки разработчика)
```bat
cl /std:c++17 /EHsc main.cpp /link gdiplus.lib user32.lib gdi32.lib
```

### MinGW
```bat
g++ -std=c++17 main.cpp -o png_pet.exe -lgdiplus -luser32 -lgdi32 -mwindows
```

### CMake (если тебе так удобнее)
```cmake
cmake_minimum_required(VERSION 3.15)
project(png_pet CXX)
set(CMAKE_CXX_STANDARD 17)
add_executable(png_pet WIN32 main.cpp)
target_link_libraries(png_pet gdiplus user32 gdi32)
```

## 🚀 Запуск

1. Положи рядом с `.exe` файл **`image.png`**
   > Путь ищется относительно папки с исполняемым файлом через `GetModuleFileNameW`. Не относительно рабочей директории.
2. Запусти `.exe`
3. Наслаждайся. Картинка появится в координатах `(200, 200)`

Если картинки нет — вылезет `MessageBoxA` с текстом:
> **"НЕ ВИЖУ КАРТИНКИ"**
> *"ААА НИЧО НЕ ПОНИМАЮ"*

Это фича, а не баг.

## 🧠 Как это работает (кратко)

```
image.png ──► Gdiplus::Bitmap ──► Gdiplus::Graphics (в DIB-секцию)
                                        │
                                        ▼
                              UpdateLayeredWindow
                                        │
                                        ▼
                                  Прозрачное окно
                                  поверх всего
```

1. Создаётся **layered-окно** с `WS_EX_LAYERED | WS_EX_TOPMOST` и без рамки (`WS_POPUP`)
2. PNG грузится в `Gdiplus::Bitmap`
3. Создаётся `CreateDIBSection` с 32-битным форматом (RGBA)
4. `Gdiplus::Graphics` рисует битмап в DIB с `CompositingModeSourceCopy`
5. `UpdateLayeredWindow` с `ULW_ALPHA` и `AC_SRC_ALPHA` пробрасывает альфу в окно
6. Профит

Координаты окна **не меняются** при перетаскивании через `WM_NCLBUTTONDOWN` — окно реально двигается системой, потому что мы прикидываемся, будто тащим за заголовок. Дёшево и сердито.

## ⚠️ Известные особенности

- 🐛 Размер окна при создании (`200, 200`) — **не совпадает** с реальным размером картинки. `UpdateLayeredWindow` это перетирает, но выглядит как магия
- 🐛 Координаты `(200, 200)` для `RenderPngToWindow` — **захардкожены**. Да, и точка позиционирования, и размер окна в `CreateWindowEx` не связаны
- 🐛 Нет обработки `WM_RBUTTONDOWN` / закрытия окна. Убивать через диспетчер задач — это часть экспириенса
- 🐛 `GdiplusStartup` вызывается, но результат не проверяется. Мы оптимисты
- 🐛 Комментарии в коде: `//80% CODE IS НЕЙРОСЛОП`, `//THIS FUNCTION IS FULL НЕЙРОSLOP`, `//SLOP TOO`, `// 50/50 SLOP`. Оставлены как исторический артефакт
